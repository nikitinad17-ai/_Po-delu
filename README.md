# По делу

Сайт-концепция услуг по созданию сайтов, приложений и систем для бизнеса.

Текущая версия: **0.2.0**, 10 октября 2026 года. Основа — последняя версия `po-delu.html`, одобренная Алексом в чате; в репозитории тот же файл назван `index.html`.

Сайт: **https://po-delu.vercel.app/**. Опубликован 10 октября 2026 года прямой загрузкой `index.html` в проект Vercel `po-delu`.

Репозиторий: **https://github.com/nikitinad17-ai/-**. Название `-` подтверждено владельцем 11 октября 2026 года. Связь GitHub → Vercel пока не настроена: коммит в этот репозиторий сам по себе не обновляет сайт.

## Запуск

Скачайте репозиторий и откройте `index.html` в браузере. Установка зависимостей, сборка и интернет не нужны: HTML, CSS и JavaScript находятся в одном файле.

Для локального HTTP-сервера при установленном Python:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000.

## Что есть

- Три направления: сайты, приложения и личные кабинеты, сложные бизнес-системы и интеграции.
- Примеры «до/после»: заявки с сайта, кабинет клиента и отчётность.
- Этапы работы, договорённости и ответы на частые вопросы.
- Выбор направления и подготовка описания задачи с сохранением введённого текста.
- Скачивание описания в TXT; раскрывающиеся ответы на вопросы; адаптивные стили.

## Границы демо

Форма **не отправляет заявку**: она создаёт текстовый файл на устройстве посетителя. Сервер, CRM, реальные контакты, аналитика и обработка заявок не подключены. Примеры на странице иллюстративные и не являются кейсами выполненных проектов.

GitHub Pages не включён. Для приёма обращений понадобятся согласованные контакты и механизм получения заявок. Telegram пока не подключён: ожидается ссылка или имя канала от владельца.
