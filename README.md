## Telegram-заявки (ветка feat/telegram-requests)

Форма отправляет направление, описание, имя и контакт через POST /api/submit-idea в Telegram. Для отправки контакт обязателен; скачивание TXT остаётся отдельной локальной функцией и не отправляет данные. При ошибке поля не очищаются. Успех показывается только после подтверждения Telegram API. При потере связи доставка может быть неоднозначной, повтор способен создать дубль.

В Vercel, проект po-delu, нужны серверные переменные TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID для Production (и Preview при тестировании). Не добавлять значения в GitHub или HTML. Бот @Podelu17_bot должен иметь возможность писать получателю: сначала нажмите Start. После изменения переменных нужен новый deployment.

index.html остаётся автономным интерфейсом без сборки и зависимостей. api/submit-idea.js — серверная функция Node.js для Vercel. При локальном открытии HTML или на GitHub Pages работает скачивание; отправка требует серверной функции.

## Защита и ограничения

Проверяются типы и длины полей, направление, Origin при наличии; текст отправляется без HTML-разметки. Есть honeypot и ограничение 3 запросов в минуту на IP в пределах одного экземпляра функции. Это базовая защита: счётчики не распределены и сбрасываются при перезапуске, поэтому для публичного трафика стоит дополнительно настроить ограничения на Vercel Firewall. Заявки не сохраняются в отдельную базу данных. Таймаут Telegram — 10 секунд; автоматических повторов нет. Токены и содержимое заявок не записываются в логи обработчика.

## Проверка

node --test tests/submit-idea.test.cjs

Проверены успешная доставка с подменённым Telegram API, валидация, неправильный Origin, honeypot, частотное ограничение, отсутствие настроек, отказ Telegram, сетевой сбой и синтаксис браузерного JavaScript. Это не полноценная браузерная проверка. Доставку в настоящий Telegram необходимо проверить после публикации.

Сохранены направления услуг, примеры до/после, FAQ, защита текста от перезаписи и скачивание описания. Примеры на странице иллюстративные. Правила работы: AGENTS.md.
